# Retrieval Engineering Lab

This repository is a collection of focused experiments exploring the core components of **production-oriented Retrieval-Augmented Generation (RAG) systems**.

Rather than building a complete application, each experiment validates a specific retrieval engineering concept through implementation and hands-on evaluation.

## Why This Exists

Effective retrieval systems are built by understanding the behavior of each component in the retrieval pipeline.

Each experiment is intentionally scoped as a proof of concept while emphasizing production-oriented engineering practices, clear documentation, and measurable outcomes.

## Reading Guide

The experiments are designed to be read **in sequence**, with each building on concepts and implementations introduced in earlier labs.

While each experiment focuses on a specific topic, together they form an incremental exploration of modern retrieval systems.

Each lab follows the same general pattern:

**Problem → Goal → Validation → Learnings**

## Topics Covered
